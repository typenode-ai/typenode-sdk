# Typenode SDK

This repository is a placeholder for a future public SDK. Previous designs and package scaffolds have been discarded. The API, architecture and implementation will be designed from scratch when development resumes.

The published `@typenode-ai/sdk@0.0.0` package is an empty name-reservation artifact and remains unchanged. This repository currently contains no SDK implementation, build tooling or deployment CLI.
